1. Introduction
Technical communication is an essential skill for engineering and technology students. Engineers need to communicate their ideas through reports, research papers, proposals, presentations, resumes, professional profiles, and posters.

AI tools can assist learners in preparing these documents by helping with:

Content organization
Grammar correction
Sentence improvement
Technical explanations
Summarization
Formatting
Professional writing
Idea generation
Content refinement
However, AI-generated content should not be accepted without verification. Learners must check whether the information is technically correct, original, relevant, and easy to understand.

The process can be represented as:

Topic Selection → Prompt Design → AI Generation → Review → Iterative Prompting → Verification → Final Document

Learners will create the following seven artifacts:

Technical Report

Each artifact requires a different communication style and structure.

3. Technical Report
A technical report presents technical information, project methodology, results, and conclusions in a structured format.

Prompt
Act as a technical writer. Prepare a technical report on
"AI-Based Smart Traffic Management System".

Include:
1. Introduction
2. Problem Statement
3. Objectives
4. Existing System
5. Proposed System
6. Methodology
7. Technologies Used
8. Results
9. Limitations
10. Future Enhancements
11. Conclusion

Use clear technical language and organize the content using suitable headings.
Do not invent experimental results or unsupported facts.
Iterative Prompt
Review the technical report for grammar, technical accuracy,
logical flow, repetition, and readability. Improve the content while
preserving the original technical meaning. Clearly identify any claims
that require verification.
Expected Improvement
The learner should obtain a report that is:

Well structured
Technically meaningful
Grammatically correct
Easy to read
Consistent in terminology
Suitable for academic submission
4. Research Abstract
A research abstract provides a concise summary of a research project.

A good abstract normally includes:

Background
Problem
Objective
Methodology
Key result
Conclusion
Prompt
Write a concise research abstract for a project titled
"AI-Based Smart Traffic Management System".

Include the research problem, objective, methodology, major findings,
and conclusion. Use formal academic language and keep the abstract
within 200 words. Do not create numerical results that were not provided.
Iterative Prompt
Improve this abstract for academic publication.
Remove unnecessary words, improve sentence clarity, maintain technical
accuracy, and ensure that the objective, methodology, results, and
conclusion are clearly connected.
5. Literature Review
A literature review summarizes and analyzes previous research related to a topic.

Prompt
Help me prepare a literature review on AI-based traffic management systems.
Organize the review according to major research approaches, technologies,
advantages, limitations, and research gaps.

Do not invent papers, authors, publication years, or research findings.
Indicate where verified academic sources are required.
Important Principle
AI should not be used to fabricate research papers or citations. Learners should obtain actual papers from reliable academic sources and use AI only to help summarize, compare, organize, or improve their understanding.

Iterative Prompt
Improve the structure of this literature review.
Group similar studies together, reduce repetition, identify differences
between approaches, and clearly state the research gap. Do not add
unverified references or claims.

7. Resume
AI can help learners organize their educational background, skills, projects, certifications, and achievements into a professional resume.

Prompt
Act as a professional technical resume writer.
Create a one-page resume for an engineering student interested in
software development and AI/data science.

Include:
- Career objective
- Education
- Technical skills
- Projects
- Certifications
- Achievements
- Relevant extracurricular activities

Use concise bullet points and professional language.
Do not add qualifications, skills, or achievements that I have not provided.
Iterative Prompt
Review this resume for grammar, clarity, professional tone,
repetition, and readability. Make the bullet points concise and
achievement-focused without inventing information.
Important Principle
AI should never invent qualifications, internships, certifications, work experience, achievements, or technical skills that the learner does not actually possess.

10. Iterative Prompting
Iterative prompting means improving an AI-generated response through multiple rounds of feedback instead of accepting the first response.

Example Process
Initial Prompt

Write a technical report about an AI-based traffic system.

↓

AI Output

Initial technical report.

↓

Improvement Prompt

Improve the organization and remove repetitive content.

↓

AI Output

Improved report.

↓

Accuracy Prompt

Check the technical claims and identify information that requires verification.

↓

AI Output

Accuracy-focused revision.

↓

Readability Prompt

Make the language clearer and easier for an engineering student to understand without removing important technical information.

↓

Final Output

A clearer, more accurate, and better-organized technical report.

Learners should check whether the content unnecessarily copies existing sources.

They should:

Use their own understanding.
Cite sources appropriately.
Avoid submitting AI-generated content as original research.
Verify references.
Paraphrase responsibly.

Appropriate headings
Short and understandable sentences
Logical flow

Conclusion
Prompt engineering can make AI a useful assistant for technical communication by helping learners generate, organize, revise, and evaluate professional content. However, the quality of the final document depends on the learner's ability to provide clear prompts, critically review AI output, verify technical information, maintain originality, and make appropriate revisions.

Therefore, the activity emphasizes AI-assisted communication rather than AI-dependent communication. Through iterative prompting and systematic evaluation, learners develop both technical writing skills and responsible AI-use skills.

# Result: 
The lab exercise resulted in the creation of a prototype concept for a personal assistant powered by large language models. Students were able to:
 Understand how to tailor LLM prompts to real-life applications.
 Foster creativity by designing features suited to their personal or academic lives.
 Learn prompt engineering techniques for optimal interaction with AI tools.
 Experience the versatility and utility of generative AI in solving everyday problems.
